# English Exam Master – Teacher Assistant Edition

เว็บแอปติวภาษาอังกฤษสำหรับเตรียมสอบครูผู้ช่วย (เวอร์ชันปรับ UI และเพิ่ม Reading Manga)

## วิธีเปิดโปรเจกต์
1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/
2. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ `english-exam-master` ใน Visual Studio Code
3. เปิด Terminal > New Terminal
4. พิมพ์ `npm install`
5. เมื่อติดตั้งเสร็จ พิมพ์ `npm run dev`
6. เปิด URL ที่ Vite แสดง (โดยปกติคือ http://localhost:5173)

## ฟังก์ชันที่มีในเวอร์ชันนี้
- Dashboard
- คลังบทเรียนพร้อมค้นหาและตัวกรอง
- ตัวอย่างบทเรียน Present Simple
- หน้า Reading Manga พร้อมภาพประกอบเรื่องสั้น คำศัพท์ คีย์เวิร์ด และแบบทดสอบจับใจความ 3 ข้อ
- UI ปรับสีสันและการ์ดให้ทันสมัย รองรับมือถือและคอมพิวเตอร์
- แบบฝึกหัด 8 ข้อ พร้อมเฉลยและคำอธิบายภาษาไทย
- บันทึกจำนวนชุดฝึกในเครื่องด้วย localStorage
- หน้า Mock Exam (เตรียมพัฒนาต่อ)
- Responsive สำหรับคอมพิวเตอร์และมือถือ

## หมายเหตุ
ชุดคำถามเป็นตัวอย่างเพื่อสาธิตระบบ ไม่ใช่ข้อสอบจริงหรือการรับรองว่าเป็นข้อสอบที่ออกสอบแน่นอน ควรตรวจสอบประกาศและขอบเขตเนื้อหาสอบครูผู้ช่วยจากหน่วยงานที่รับสมัครในแต่ละรอบ
